# Ground texture sources

All source colour and OpenGL normal maps below are from [Poly Haven](https://polyhaven.com) and licensed [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). `tools/textures.py` resizes the maps and writes the runtime textures and their average colours.

## Desert

2K sources: `sand_01`, `sand_02`, `coast_sand_01`, `damp_sand`, `mud_cracked_dry_03`, and `rock_face_03`.
