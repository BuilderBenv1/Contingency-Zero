# Contingency Zero

A machine-war RTS in the spirit of Total Annihilation, with Red Alert 2's readability and isometric look. Two rival machine factions, a flow economy, wreckage you reclaim, and a Commander you can't afford to lose. Built in Godot 4 with C#.

## Play it

Download the latest build from **[Releases](https://github.com/BuilderBenv1/Contingency-Zero/releases)**:

- **Windows:** unzip and run `ContingencyZero.exe`. If SmartScreen warns about an unsigned app, choose *More info → Run anyway*.
- **Linux:** extract and run `./ContingencyZero.x86_64`.

`HOW_TO_PLAY.txt` in the download covers controls and a first match. You don't need Godot to play.

## What's in the game

- **Skirmish:** you against up to seven computer players on fourteen maps, at four difficulties:
  - **Easy:** one factory and slow attacks.
  - **Normal:** scouts, expands and attacks in waves.
  - **Hard:** a bigger economy, staged attack waves, and uses the Breach Cannon.
  - **Brutal:** Hard plus full map vision and 50% more income.
- **Campaign:** five missions each for the Lattice and the Crucible. They cover:
  - economy basics, outposts and artillery;
  - holding out against waves;
  - air and naval warfare;
  - a two-on-two finale.
- **Multiplayer:** host or join by IP over a LAN or the internet. It uses lockstep networking with desync detection, and computer players can join the same match. Internet play needs UDP port 7777 forwarded on the host.
- **Map editor:** includes:
  - terrain sculpting: raise, lower, smooth, flatten, plateau and roughen;
  - water level and theme;
  - metal spots, trees, rocks and start positions;
  - symmetry modes, undo/redo, a passability view, playability checks and one-click test play.

  Saved maps show up in Skirmish and Multiplayer.
- **Replays:** every match is saved, so you can watch it back at any speed from any player's view.

### Total Annihilation mechanics

- **Flow economy:** metal and energy are spent continuously. When income falls short, everything slows evenly (a stall) rather than queueing.
- **Reclaim:** wrecks, rocks and trees can be turned back into metal and energy.
- **Nanoframes:** builders assist each other and factories. Construction shows as a growing hologram.
- **Commander and Breach Cannon:** the Breach Cannon (D-gun) destroys almost anything it touches.
- **Unit orders:** attack-move, patrol, guard and fire states.
- **Intel and veterancy:** fog of war, radar and veterancy.
- **Two factions:**
  - **Lattice:** faster, with longer range and better sight.
  - **Crucible:** tougher and better at salvage.
- **43 units and structures per faction** across land, sea and air, up to experimentals.

Sound effects and music are generated in code. Units and buildings are 3D models built by Blender scripts in `tools/models/` (`kit.py` plus one script per unit). The old-school look's ground and hull textures come from [ambientCG](https://ambientcg.com) (CC0), shrunk and prepared by `tools/textures.py`. The desert and temperate ground layers come from [Poly Haven](https://polyhaven.com) (CC0), with colour + normal maps in `tools/source_textures/`; individual assets are credited in `tools/source_textures/README.md`. Battlefield clutter (ruined walls, houses, field walls, barrels, crates) is generated in code (`game/src/View/Meshes/ClutterModels.cs`) - no external assets.

## Layout

| Folder | What |
| --- | --- |
| `sim/` | The game itself: plain C#, no Godot types. Fixed-point maths, world, economy, combat, pathing, vision, AI, missions, replays |
| `sim.tests/` | xUnit tests: maths, economy, combat, pathing, AI, missions, determinism and golden hashes, source rules |
| `game/` | Godot 4.3 .NET project. Rendering, input, UI, audio, map editor, networking. Reads the sim and sends commands; never writes sim state |
| `data/units/` | Unit stats as JSON, generated by `tools/unitgen.py` (balance lives there) |
| `data/maps/` | Built-in maps, generated by `tools/mapgen.py` |
| `data/missions/` | Campaign missions as JSON scripts |
| `docs/` | Player-facing notes shipped with releases |

## Building from source

```bash
dotnet test                                      # all sim tests
dotnet build game/ContingencyZero.Game.csproj    # the Godot C# project compiles
```

To run it from source, open `game/project.godot` in **Godot 4.3+ (.NET edition)** and press Play.

Releases are built by GitHub Actions (`.github/workflows/release.yml`). To make one, bump `VERSION`, then push `main` to the `release-check` branch: this builds Windows and Linux zips into a draft release, and you press **Publish** on GitHub. Pushing a `v*` tag works too.

## Rules for the sim

Read [CLAUDE.md](CLAUDE.md) before changing anything in `sim/`. In short: no floats, no `System.Random`, no clocks, ordered iteration only, every change tested. A test scans the sim source and fails if any of those slip in. CI checks that the golden hashes match on Linux, Windows and macOS, so a match plays out identically everywhere. Multiplayer and replays depend on that.
